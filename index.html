LunaCat 개인정보 처리방침

최종 수정일: 2026년 8월 14일 · 시행일: 2026년 8월 14일

LunaCat은 생리 주기를 기록하고 예측하는 앱입니다. 이 앱이 다루는 기록은 매우 민감한 건강 정보이기 때문에, 모든 데이터를 사용자의 기기 안에만 저장하며 외부로 전송하지 않습니다. 회원가입도, 로그인도, 서버도 없습니다.

1. 수집하는 정보

LunaCat은 사용자가 직접 입력한 다음 정보를 기기 내에서만 처리합니다.

  • 생리 시작일 및 생리 기간
  • 증상, 기분, 질 분비물 기록
  • 성관계 및 피임 기록
  • 경구 피임약 복용 여부
  • 앱 사용 목표, 영양제 복용 여부, 유방 검사 이력 등 온보딩 선택 항목

위 정보는 모두 건강 관련 민감 정보에 해당하며, Apple 및 Google의 건강 데이터 정책에 따라 취급됩니다. 이름, 이메일, 전화번호, 위치 정보, 광고 식별자는 일절 수집하지 않습니다.

2. 데이터 저장 위치

모든 데이터는 사용자 기기의 로컬 저장소에만 저장됩니다.

  • 외부 서버로 전송하지 않습니다.
  • 개발사의 클라우드에 백업하지 않습니다.
  • 제3자와 공유하거나 판매하지 않습니다.
  • 광고 목적으로 사용하지 않습니다.

사용자가 기기 자체의 백업 기능(iCloud 백업, Google 백업 등)을 켜 둔 경우, 앱 데이터가 해당 백업에 포함될 수 있습니다. 이는 사용자와 OS 제공사 사이의 설정이며 LunaCat은 그 데이터에 접근할 수 없습니다.

3. 데이터 보안

  • 기기의 자체 암호화(iOS Data Protection, Android 파일 기반 암호화)로 보호됩니다.
  • 앱 잠금(Face ID·지문)으로 앱 실행 자체를 잠글 수 있습니다.
  • 스크린샷·화면 녹화 차단, 알림 내용 숨기기로 화면 노출을 줄일 수 있습니다.

4. 사용자 권리

사용자는 언제든지 다음을 수행할 수 있습니다.

  • 데이터 내보내기 — 설정 > 데이터 내보내기에서 전체 기록을 JSON 형식으로 내보낼 수 있습니다.
  • 데이터 삭제 — 설정 > 데이터 전체 삭제로 모든 기록을 즉시, 영구적으로 지울 수 있습니다.
  • 앱 삭제 — 앱을 삭제하면 기기에 저장된 모든 데이터가 함께 제거됩니다.

데이터가 서버에 존재하지 않으므로, 열람·정정·삭제 요청을 위해 개발사에 연락할 필요가 없으며 사용자가 직접 즉시 처리할 수 있습니다.

5. 제3자 서비스

LunaCat은 분석·광고·추적 SDK를 사용하지 않습니다.

  • 분석 도구(Google Analytics 등) 미사용
  • 소셜 로그인 SDK 미사용
  • 광고 네트워크 미사용
  • 사용자 행동 추적 및 기기 간 식별 미사용

6. 알림

알림은 사용자가 켠 경우에만 발송되며, 모든 알림은 기기 안에서 예약되고 발송됩니다. 알림 내용을 만들기 위해 데이터를 외부로 보내지 않습니다. 알림은 언제든 설정에서 끌 수 있습니다.

7. 미성년자 보호

LunaCat은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 고의로 수집하지 않습니다. 앱은 어떠한 개인 식별 정보도 서버로 전송하지 않으므로 개발사가 보유하는 아동 데이터는 존재하지 않습니다.

8. 의료 면책

LunaCat은 의료 기기가 아닙니다. 앱이 제공하는 주기 예측, 가임기·배란 예측, 건강 정보는 참고용이며 의학적 진단이나 치료를 대체하지 않습니다.

특히 가임기 예측은 피임 수단이 아닙니다. 임신, 피임, 질병에 관한 결정은 반드시 의료 전문가와 상담하세요.

9. 정책 변경

이 처리방침이 변경되는 경우 앱 업데이트와 이 페이지를 통해 안내합니다. 수집 항목이나 데이터 처리 방식이 실질적으로 바뀌는 경우에는 앱 내에서 다시 동의를 받습니다.
